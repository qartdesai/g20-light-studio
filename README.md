# G20 Light Studio

Редактор световых сцен для BMW G20 318 2021 года. Версия 0.1.0 работает в режиме предпросмотра. Одна и та же сцена проигрывается в настольной студии и в приложении для MGU Store / iDrive 7. Физическое управление оптикой ожидает подтверждения каналов и транспорта на конкретной машине.

## Попробовать на компьютере

Скачай [G20-Light-Studio.html](./G20-Light-Studio.html) кнопкой **Download raw file** и открой файл в Chrome, Edge или Safari. Всё работает локально. Выбери «Аварийка» или «По периметру» и нажми «Проиграть». В редакторе можно выбрать одну ручку или один сегмент, задать длительность и добавить шаг. Пустой шаг задаёт паузу. Чтобы проверить свою сцену, нажми «Сохранить сцену», затем «Проиграть». Сохранённые сцены привязаны к браузеру. JSON подходит для переноса и резервной копии.

Для музыки раскрой «В такт музыке», выбери локальный аудиофайл и нажми «Под музыку». Студия ищет нарастания громкости в треке и переключает шаг по их времени. На музыке со слабо выраженной атакой результат может расходиться с ритмом. На MGU в этой версии доступен ручной такт.

## Открыть в MGU Store

На уже настроенном MGU Store открой настройки источников, добавь **qartdesai/g20-light-studio**, выбери ветку **main**, затем **G20 Light Studio**. Пакет рассчитан на iDrive 7. В машине открой приложение в меню приложений. Пункты «Ручной выбор огней», «Эффекты» и «Моя сцена» работают на экране головного устройства. Первое испытание на реальной G20 ещё предстоит.

## Что можно выбирать

- Левая и правая фары, ДХО, ближний и дальний свет, передние и задние поворотники, повторители зеркал, ПТФ, подсветка дверей и приветственный свет.
- Четыре ручки по отдельности, стопы с левой и правой стороны, центральный стоп, задний ход, габариты и две лампы номера.
- Дополнительные сегменты каждой передней фары, наружных и внутренних секций стопов с обеих сторон и центрального стопа. Идентификатор каждого сегмента независим. Аварийка запускает мигание шести зон поворотников.
- Предпросмотр рассчитан на сочетания выбранных каналов. Длительность шага от 100 мс до 10 с, до 128 шагов на сцену. Есть изменение порядка, замена, удаление, скорость, цикл и 1–3 прохода.

### Профиль конкретной машины

[Профиль](./profiles/g20-318-2021.json) задаёт список блоков, количество демонстрационных сегментов и их положение на схеме. Начальные числа служат для проверки редактора. Количество независимых выходов, комплектация оптики и способ передачи команд для этой машины пока неизвестны. Коды кузовных опций сами по себе не подтверждают раздельное включение диодов.

Когда появится карта оптики, для каждого выхода нужны расположение и сторона, обозначение фары или блока, какая секция загорается и какие загораются вместе. Для привязки понадобятся документированный интерфейс включения и штатного возврата управления, версия блока и проверка на стоящей машине. Изменение количества сегментов в профиле применяется командой `node tools/build-profile.js`, затем `node tools/build-studio.js`. Сохраняй прежние идентификаторы, чтобы существующие сцены сохраняли смысл.

### Обмен сценами с MGU

1. В студии экспортируй сцену кнопкой «Скачать JSON».
2. В копии репозитория выполни `node tools/add-pack.js путь/к/сцене.json`, затем `node tools/build-studio.js`. Набор с тем же названием заменится.
3. Опубликуй изменения в ветке источника и обнови приложение в Store. Сцена появится в разделе «Эффекты». На MGU также можно составить и сохранять свои сцены в восьми слотах редактора.

## Проверенные возможности BimmerLight и статус проекта

| Возможность | G20 Light Studio 0.1.0 |
|---|---|
| Управление световыми функциями, в том числе с одной стороны | Ручной выбор в симуляторе, физические выходы ожидают проверки |
| Готовые шоу, повтор, регулировка числа вспышек | 26 оригинальных пресетов в демопрофиле, скорость, цикл и 1–3 прохода всей сцены. Число вспышек отдельного огня задаётся шагами |
| Создание, изменение, порядок, удаление и обмен наборами | Доступны в настольной студии. MGU умеет редактировать свою сцену и открывать наборы из пакета |
| Музыка и ручной такт | Анализ аудиофайла на компьютере, ручной такт на обеих платформах. Захват звука штатной магнитолы требует отдельной интеграции |
| Определение машины и блоков, фильтрация неподдерживаемых действий, адаптеры OBD/BLE/Wi-Fi/ENET, переподключение | Для реального автомобиля не реализовано |
| Возврат управления штатной системе, диагностика ошибок по блокам, обратная связь на приборке | Требуют интеграции с автомобилем. «Стоп» сейчас очищает предпросмотр |
| Быстрый доступ с CarPlay, виджеты и повторное подключение при старте CarPlay | В версии для iDrive вход через собственный пункт меню MGU. Компоненты телефонных платформ не реализованы |

Описание продукта и функций опубликовано на [сайте BimmerLight](https://bimmerlight.com/), в [FAQ](https://bimmerlight.com/faq/) и в [истории версий App Store](https://apps.apple.com/gb/app/bimmerlight-for-bmw-mini-rr/id6745905907). Каталог MGU подготовлен по [формату публикации MGU Store](https://github.com/robertnisipeanu/mgu-store/blob/main/docs/PUBLISHING.md). Это самостоятельный проект со своими сценами и интерфейсом.

## Разработка

Для настольной сборки и тестов достаточно Node.js 18 или новее. Зависимостей npm нет.

```sh
node tools/build-profile.js
node tools/build-studio.js
node tests/run.js
```

Исходники MGU находятся в `apps/qart_lightstudio`. Store собирает пакет на головном устройстве, используя локальный SDK. Компоненты RHMI и платформенный манифест подготовлены с помощью [MGU App Kit](https://github.com/cauliflowermossgrape/idrive7-apps), его лицензия включена в [licenses/idrive7-apps.txt](./licenses/idrive7-apps.txt).
